# 💥 금보 vs 빅금보
포트리스식 턴제 포격 폰 웹게임. 금보(80kg)와 10년 뒤에서 온 빅금보(120kg)가 서로 음식을 던져서 상대 배를 먼저 터뜨리면 승리.
- 조작: 화면 아무 데나 누르고 뒤로 당겼다 놓기(새총) = 발사, ◀ ▶ 꾹 = 걷기
- 금보 무기: 🥗 샐러드 · 💬 "내일부터" 말풍선(튕김) · 🏋️ 덤벨 · 🥊 필살 관장님 3연발
- 빅금보 무기: 🍗 치킨 · 🍜 불닭(불 장판) · 🍕 피자(분열) · 🎂 필살 케이크
- 아이템: 🪞 거울셀카 · 🛵 배달 · ✌️ 더블 · 📖 책읽기, 친구 난입 이벤트, 치킨 냄새 바람
- 모드: CPU전(금보/빅금보 선택, 난이도 3단계), 한 폰 2인용
